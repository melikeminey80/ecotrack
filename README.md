# ♻️ EcoTrack - Smart Waste Tracking & Recycling System

A web-based recycling tracking platform that encourages users to actively participate in recycling processes by earning points and redeeming rewards.

## 🌱 About the Project

Users can deliver various types of waste to designated collection points and earn points. These points can be used for rewards and campaigns. The system supports two user types: **individual** and **corporate**.

### Features
- User registration & login (SHA-256 password hashing)
- Waste delivery tracking with QR code simulation
- Point calculation system
- Reward redemption
- Dynamic leaderboard (AJAX-powered, no page refresh)
- Responsive design
